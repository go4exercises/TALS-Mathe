Formelauszug

Ergänzung zur Formelsammlung Promath (SBFI). Notation gemäss Formeln, Tabellen, Begriffe (FTB).

Rechtwinkliges Dreieck

BeziehungFormel
Sinus\(\sin(\alpha) = \dfrac{\text{Gegenkathete}}{\text{Hypotenuse}} = \dfrac{a}{c}\)
Cosinus\(\cos(\alpha) = \dfrac{\text{Ankathete}}{\text{Hypotenuse}} = \dfrac{b}{c}\)
Tangens\(\tan(\alpha) = \dfrac{\text{Gegenkathete}}{\text{Ankathete}} = \dfrac{a}{b} = \dfrac{\sin(\alpha)}{\cos(\alpha)}\)
Pythagoras\(a^2 + b^2 = c^2\)
Trigonom. Pythagoras\(\sin^2(\alpha) + \cos^2(\alpha) = 1\)
Winkelsumme\(\alpha + \beta = 90°\) (im rechtwinkligen Dreieck)

Umkehrfunktionen (Arcusfunktionen)

GleichungAuflösung nach αTaschenrechner
\(\sin(\alpha) = w\)\(\alpha = \arcsin(w)\)SHIFT + sin
\(\cos(\alpha) = w\)\(\alpha = \arccos(w)\)SHIFT + cos
\(\tan(\alpha) = w\)\(\alpha = \arctan(w)\)SHIFT + tan
