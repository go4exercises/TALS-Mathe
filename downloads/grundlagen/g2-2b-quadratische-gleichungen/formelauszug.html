Quadratische Gleichungen — Formelauszug

Ergänzung zur Formelsammlung Promath (SBFI). Notation gemäss Formeln, Tabellen, Begriffe (FTB).

1. Formen

Allgemeine Form \( a \cdot x^2 + b \cdot x + c = 0 \) mit \( a \neq 0 \)
Normierte Form (pq-Form) \( x^2 + p \cdot x + q = 0 \) — durch Division durch \(a\)

2. Vier Lösungsverfahren

MethodeBedingungLösung
Reinquadratisch\(b = 0\) falls \(-c/a \geq 0\): \(x_{1,2} = \pm \sqrt{-c/a}\); sonst \(\mathbb{L} = \emptyset\)
Ausklammern \(c = 0\) \(x_1 = 0,\;\; x_2 = -b/a\)
Mitternachtsformel (abc)universell \(x_{1,2} = \dfrac{-b \pm \sqrt{b^2 - 4ac}}{2a}\)
pq-Formel normierte Form, \(a = 1\) \(x_{1,2} = -\dfrac{p}{2} \pm \sqrt{\left(\dfrac{p}{2}\right)^2 - q}\)

3. Diskriminante

FallWurzelterm \(\sqrt{D}\)Lösungsmenge
\(D > 0\)positive reelle Zahl \(\mathbb{L} = \{x_1, x_2\}\) — zwei verschiedene
\(D = 0\)\(\sqrt{0} = 0\) \(\mathbb{L} = \{-b/(2a)\}\) — doppelte Lösung
\(D < 0\)in \(\mathbb{R}\) nicht definiert \(\mathbb{L} = \emptyset\)

Mit \(D = b^2 - 4 \cdot a \cdot c\). In der pq-Formel: \(D' = (p/2)^2 - q\) — selbe Aussage.

4. Satz von Vieta (für die normierte Form)

Summe der Lösungen \(x_1 + x_2 = -p\)
Produkt der Lösungen \(x_1 \cdot x_2 = q\)

Anwendung: bei einfachen ganzzahligen Lösungen schneller als pq-Formel — gesucht zwei Zahlen mit Summe \(-p\) und Produkt \(q\).

5. Vorgehen — Schritt für Schritt

Schritt 1Klammern auflösen, alles auf eine Seite bringen, sortieren zu \(a x^2 + b x + c = 0\)
Schritt 2Spezialfall prüfen: \(b = 0\)? \(c = 0\)? Falls ja, dort lösen
Schritt 3Sonst: Diskriminante \(D = b^2 - 4ac\) berechnen, Anzahl Lösungen ablesen
Schritt 4Mitternachts- oder pq-Formel anwenden (pq nur bei \(a = 1\))
Schritt 5Probe — Vieta oder Einsetzen in die ursprüngliche Gleichung

6. Parameter-Diskussion über \(D(k)\)

BereichDiskriminanteLösungsmenge
\(D(k) > 0\) positiv zwei reelle Lösungen
\(D(k) = 0\) null eine doppelte Lösung
\(D(k) < 0\) negativ \(\mathbb{L} = \emptyset\)
\(a(k) = 0\) — Sonderfall: Gleichung wird linear

7. Faktorisieren — drei Sub-Methoden

MethodeWann?Vorgehen / Beispiel
x ausklammern (\(c = 0\)) konstantes Glied fehlt \(2x^2 - 8x = 2x(x - 4) = 0\) → \(x_1 = 0,\, x_2 = 4\)
Binom erkennen Mittelterm \(= \pm 2 a b\) \(x^2 - 6x + 9 = (x - 3)^2 = 0\) → \(x = 3\) (doppelt)
Zweiklammersatz / Vieta ganzzahlige Lösungen \(x^2 - 5x + 6 = (x - 2)(x - 3) = 0\) → \(x_1 = 2,\, x_2 = 3\)

Stolperstein bei \(c = 0\): nicht durch \(x\) teilen, sonst geht die Lösung \(x = 0\) verloren.
