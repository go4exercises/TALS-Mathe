Intervalle

NotationBedeutung
\([a; b]\)\(a \le x \le b\) (geschlossen)
\(]a; b[\)\(a < x < b\) (offen)
\([a; b[\)\(a \le x < b\) (halboffen)
\(]a; b]\)\(a < x \le b\) (halboffen)
\([a; \infty[\)\(x \ge a\)
\(]-\infty; b]\)\(x \le b\)

Konventions-Hinweis: In der Schweiz (und in Frankreich) wird die nach aussen gewendete eckige Klammer verwendet — \(]a; b[\) ist offen. Im angelsächsischen Raum (USA, UK) ist die übliche Schreibweise \((a, b)\) für offen und \([a, b]\) für geschlossen, mit Komma statt Strichpunkt. Beide Konventionen meinen dasselbe.

Vorzeichenregeln

OperationRegel
\((+)\cdot(+)\)\(=\,+\)
\((-)\cdot(-)\)\(=\,+\)
\((+)\cdot(-)\)\(=\,-\)
\((-)\cdot(+)\)\(=\,-\)
\(a-(-b)\)\(=a+b\)
\(a+(-b)\)\(=a-b\)

Hierarchie der Operationen

  1. Klammern (innerste zuerst)
  2. Potenzen, Wurzeln
  3. \(\cdot\,\), \(:\)
  4. \(+\,\), \(-\)

Betrag und Ordnung

\(|a| = a\) für \(a \ge 0\), \(|a| = -a\) für \(a < 0\). Beispiel: \(|{-7}|=7\).

Negative Zahlen: \(-7 < -3 < 0 < 3 < 7\).
