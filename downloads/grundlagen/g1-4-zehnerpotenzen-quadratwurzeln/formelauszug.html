Wissenschaftliche und Engineering-Notation

Wissenschaftliche Notation: \(a \cdot 10^n\) mit \(1 \le |a| < 10,\ n \in \mathbb{Z}\). Mantisse genau eine Ziffer vor dem Dezimalpunkt.

Engineering-Notation: \(a \cdot 10^n\) mit \(1 \le |a| < 1000\) und \(n\) Vielfaches von 3. Exponent passt direkt auf einen SI-Vorsatz.

Wurzelgesetze

\(\sqrt{a} = a^{1/2}\) — die Wurzel ist eine Potenz mit Bruchexponent.

Nr.Gesetz (Wurzelform)als BruchexponentVoraussetzung
W0\(\sqrt[n]{a} = a^{1/n}\)\(a^{1/n}\)\(a \ge 0,\, n \in \mathbb{N}^*\)
W1\(\sqrt{a} \cdot \sqrt{b} = \sqrt{ab}\)\(a^{1/2} b^{1/2} = (ab)^{1/2}\)\(a, b \ge 0\)
W2\(\dfrac{\sqrt{a}}{\sqrt{b}} = \sqrt{\dfrac{a}{b}}\)\(\dfrac{a^{1/2}}{b^{1/2}} = \left(\dfrac{a}{b}\right)^{1/2}\)\(a \ge 0,\, b > 0\)
W3\(\sqrt{\sqrt{a}} = \sqrt[4]{a}\)\((a^{1/2})^{1/2} = a^{1/4}\)\(a \ge 0\)
W4\(\sqrt{ab} = \sqrt{a} \cdot \sqrt{b}\)\((ab)^{1/2} = a^{1/2} b^{1/2}\)\(a, b \ge 0\)
W5\(\sqrt{\dfrac{a}{b}} = \dfrac{\sqrt{a}}{\sqrt{b}}\)\(\left(\dfrac{a}{b}\right)^{1/2} = \dfrac{a^{1/2}}{b^{1/2}}\)\(a \ge 0,\, b > 0\)
W6\(\sqrt{1} = 1\)\(1^{1/2} = 1\)—
W7\(\dfrac{1}{\sqrt{a}} = \sqrt{\dfrac{1}{a}}\)\(\dfrac{1}{a^{1/2}} = a^{-1/2}\)\(a > 0\)
W8\((\sqrt{a})^2 = a\)\((a^{1/2})^2 = a\)\(a \ge 0\)
W9\(\sqrt{a^2} = |a|\)\((a^2)^{1/2} = |a|\)\(a \in \mathbb{R}\)

Teilweises Wurzelziehen

\(\sqrt{12} = 2\sqrt{3}\) \(\sqrt{18} = 3\sqrt{2}\) \(\sqrt{20} = 2\sqrt{5}\) \(\sqrt{50} = 5\sqrt{2}\)
\(\sqrt{72} = 6\sqrt{2}\) \(\sqrt{75} = 5\sqrt{3}\) \(\sqrt{200} = 10\sqrt{2}\) \(\sqrt{x^3} = x\sqrt{x}\) (\(x \ge 0\))

Nenner rational machen

\(\dfrac{1}{\sqrt{a}} = \dfrac{\sqrt{a}}{a}\) (einfacher Nenner)

\(\dfrac{1}{\sqrt{a}+b} = \dfrac{\sqrt{a}-b}{a - b^2}\) (Summen-Nenner, 3. binomische Formel)
