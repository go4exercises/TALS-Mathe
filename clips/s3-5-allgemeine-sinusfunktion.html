gilt für\(y = a\sin(bx + c)\)
Die ausmultiplizierte Form
\(y = \fa{a}\sin(\fb{b}x + \fc{c})\)
\(c\) ist nicht die Verschiebung. Das ist die häufigste Falle.
\(\fa{a}\sin(\fb{b}x + \fc{c}) = \fa{a}\sin\!\left(\fb{b}\left(x + \tfrac{\fc{c}}{\fb{b}}\right)\right)\)
\(p = \dfrac{2\pi}{\fb{b}} \qquad x_0 = -\dfrac{\fc{c}}{\fb{b}}\)
Die Amplitude bleibt \(|a|\) — sie hängt an keiner der beiden.
\(y = \fa{3}\sin(\fb{2}x \fc{- \tfrac{\pi}{2}})\)
\(\text{Amplitude } = \fa{3} \qquad p = \dfrac{2\pi}{\fb{2}} = \pi\)
\(x_0 = -\dfrac{\fc{-\pi/2}}{\fb{2}} = \fc{\dfrac{\pi}{4}} \quad \text{nach rechts}\)
Zwei Minus heben sich auf — darum nach rechts.
Eine volle Welle von \(\tfrac{\pi}{4}\) bis \(\tfrac{\pi}{4} + \pi\).
Aus dem Graphen zur Gleichung — in dieser Reihenfolge:
1Amplitude ablesen \(\longrightarrow\) \(a\)
2Periode \(p\) ablesen \(\longrightarrow\) \(b = \tfrac{2\pi}{p}\)
3steigende Nullstelle \(x_0\) ablesen \(\longrightarrow\) \(c = -b\,x_0\)
\(c\) kommt zuletzt — es braucht \(b\).
Zwei Brüche, eine Kurve.
\(p = \dfrac{2\pi}{b} \qquad x_0 = -\dfrac{c}{b}\)
Beide haben \(b\) im Nenner. Wer \(b\) hat, hat den Rest.
