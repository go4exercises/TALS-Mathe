0.40	Steht in einer Gleichung eine Klammer oder ein Bruch, räumst du zuerst auf: Klammern auflösen, Brüche mit dem Hauptnenner wegschaffen. Erst dann sortierst du wie gewohnt.
10.26	Vier mal Klammer x minus zwei gleich zwei x plus sechs. Die Vier vor der Klammer multipliziert jedes Glied: vier x minus acht. Dann wie gewohnt: minus zwei x und plus acht gibt zwei x gleich vierzehn, also x gleich sieben.
25.78	Steht vor der Klammer ein Minus, dreht es jedes Vorzeichen in der Klammer. Fünf minus zwei mal Klammer x plus eins: Minus zwei mal x gibt minus zwei x, minus zwei mal eins gibt minus zwei. Zusammengefasst: drei minus zwei x gleich x. Plus zwei x: drei gleich drei x, also x gleich eins.
44.60	Bei Brüchen multiplizierst du beide Seiten mit dem Hauptnenner, hier sechs. Jedes Glied mal sechs: aus x Drittel wird zwei x, aus zwei wird zwölf, aus x Halbe wird drei x, aus minus eins wird minus sechs. Sortiert: achtzehn gleich x. Probe: sechs plus zwei ist acht, neun minus eins auch acht.
64.31	Ein Bruchstrich wirkt wie eine Klammer. Mal sechs gibt drei mal Klammer x minus eins, minus zwei mal Klammer x plus eins, gleich sechs. Das Minus vor dem zweiten Bruch gilt für den ganzen Zähler: minus zwei x minus zwei. Zusammengefasst: x minus fünf gleich sechs, also x gleich elf.
82.77	Zum Mitnehmen: Der Faktor vor einer Klammer gilt für jedes Glied, ein Minus davor dreht jedes Vorzeichen. Brüche verschwinden mit dem Hauptnenner: jedes Glied mal den Hauptnenner, auch die Zahlen ohne Bruch.
