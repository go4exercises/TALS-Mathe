Plus fünf oder minus fünf?
Die Erkenntnisse zur Animation «Scheinlösungs-Labor: \(\sqrt{6x+7} = \pm 5\)»
\(\fa{\sqrt{6x+7}} = \fb{\pm 5}\)
Sieht das Quadrieren den Unterschied?
\(\fa{\sqrt{6x+7}} = \fb{5} \;\Rightarrow\; 6x + 7 = 25 \;\Rightarrow\; \fc{x = 3}\)
Probe: \(\sqrt{6\cdot 3+7} = \sqrt{25} = 5\) ✓, also \(L = \{3\}\)
Ein Schnittpunkt \(\fc{(3 \mid 5)}\)
\(\fa{\sqrt{6x+7}} = \fb{-5} \;\Rightarrow\; 6x + 7 = 25 \;\Rightarrow\; x = 3\)
Probe: \(\sqrt{25} = 5 \fd{\neq -5}\), also \(L = \{\,\}\)
\(x = 3\) ist eine Scheinlösung.
Quadrieren verliert das Vorzeichen.
\((\fb{+5})^2 = (\fb{-5})^2 = 25\)
Die Probe in der Ausgangsgleichung ist Pflicht.
