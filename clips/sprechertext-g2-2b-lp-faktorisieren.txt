0.40	Ein Produkt ist genau dann null, wenn mindestens ein Faktor null ist. Darauf beruht das Faktorisieren: Steht rechts null und links ein Produkt, setzt man jeden Faktor null.
10.63	Fehlt das konstante Glied, klammere x aus. x Quadrat gleich fünf x: Minus fünf x gibt x Quadrat minus fünf x gleich null. Ausgeklammert: x mal Klammer x minus fünf. Also ist x gleich null oder x gleich fünf.
24.64	Wer durch x teilt, erhält nur x gleich fünf. Die Lösung null geht verloren, denn Teilen durch x setzt voraus, dass x nicht null ist.
33.27	Manchmal steht ein Binom da. x Quadrat minus sechs x plus neun ist Klammer x minus drei, im Quadrat. Die Gleichung hat nur eine Lösung: drei. Die Parabel berührt die x-Achse.
44.83	Sonst hilft oft der Zweiklammersatz. Bei x Quadrat minus sieben x plus zwölf suchst du die beiden Lösungen: Ihr Produkt ist zwölf, ihre Summe sieben, das Gegenteil von minus sieben. Das sind drei und vier. Also Klammer x minus drei mal Klammer x minus vier gleich null.
61.82	Dahinter steckt der Satz von Vieta. Für x Quadrat plus p x plus q gleich null gilt: Die Summe der Lösungen ist minus p, ihr Produkt ist q. Damit kannst du jede Lösung auch kontrollieren.
73.86	Zum Mitnehmen: Rechts muss null stehen. Dann ausklammern, ein Binom erkennen oder die beiden Lösungen über ihr Produkt und ihre Summe finden. Nie durch x teilen.
