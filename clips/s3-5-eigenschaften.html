Drei Steckbriefe
\(\sin x \qquad \cos x \qquad \tan x\)
Definitionsmenge, Wertemenge, Periode, Nullstellen, Symmetrie.
\(\fa{\sin x} = 0 \quad \longrightarrow \quad x = k\pi\)
\(\fb{\cos x} = 0 \quad \longrightarrow \quad x = \tfrac{\pi}{2} + k\pi\)
\(\fd{\tan x} = 0 \quad \longrightarrow \quad x = k\pi\)
Der Tangens erbt die Nullstellen von seinem Zähler.
\(\cos\) an der \(y\)-Achse gespiegelt, \(\sin\) am Ursprung gedreht.
\(\fb{\cos(-x) = \cos x} \qquad \text{gerade}\)
\(\fa{\sin(-x) = -\sin x} \qquad \text{ungerade}\)
\(\fd{\tan(-x) = -\tan x} \qquad \text{ungerade}\)
Gerade heisst achsensymmetrisch, ungerade punktsymmetrisch.
Zwei Wellen, ein Sonderling
\(\fa{\sin},\ \fb{\cos}: \ W = [-1,\,1],\ p = 2\pi\)
\(\fd{\tan}: \ W = \mathbb{R},\ p = \pi,\ \text{Pole bei } \tfrac{\pi}{2} + k\pi\)
Alles andere folgt daraus.
