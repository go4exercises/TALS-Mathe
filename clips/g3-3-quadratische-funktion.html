Ein x² — und alles ändert sich
\(f(x) = ax^2 + bx + c \qquad (a \neq 0)\)
\(a \neq 0\) gehört dazu: sonst bleibt eine lineare Funktion übrig.
\(\text{linear: } \ 2x-1 \ \longrightarrow \ \text{Zuwachs immer } 2\)
\(\text{quadratisch: } \ x^2 \ \longrightarrow \ 1,\ 3,\ 5,\ 7,\ \ldots\)
\(0 \to 1 \to 4 \to 9 \to 16\): die Zuwächse sind \(1, 3, 5, 7\) —
sie wachsen selbst. Darum krümmt sich der Graph.
Symmetrisch zur Senkrechten durch den Scheitelpunkt.
\(a > 0 \ \longrightarrow \ \text{nach oben} \ \longrightarrow \ \text{Scheitel ist Minimum}\)
\(a < 0 \ \longrightarrow \ \text{nach unten} \ \longrightarrow \ \text{Scheitel ist Maximum}\)
Das sieht man dem Term sofort an — man muss nichts rechnen.
Der Betrag von \(a\) sagt zusätzlich, wie schmal die Parabel ist.
x² macht die Parabel.
a macht die Öffnung.
Die Gerade hat keinen ausgezeichneten Punkt.
Die Parabel hat einen: den Scheitelpunkt.
Er ist der Bezugspunkt für fast alles, was folgt.
