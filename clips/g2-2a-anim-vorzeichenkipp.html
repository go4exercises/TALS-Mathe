Warum kippt das Zeichen?
Die Erkenntnisse zur Animation «Vorzeichenkipp beim Multiplizieren»
\(\fa{2} \lt \fb{5} \quad \mid \cdot k\)
Was passiert mit der Reihenfolge, wenn \(k\) negativ wird?
\(\fa{2}\cdot 2 = \fa{4} \lt \fb{10} = \fb{5}\cdot 2\)
Positives \(k\) streckt: Die Reihenfolge bleibt.
Das Zeichen bleibt \(\lt\).
\(\fa{2}\cdot 0 = 0 \qquad \fb{5}\cdot 0 = 0 \;\Longrightarrow\; 0 = 0\)
Beide Bilder fallen auf die Null.
Multiplikation mit \(0\) ist keine Äquivalenzumformung.
\(\fa{2}\cdot(-2) = \fa{-4} \gt \fb{-10} = \fb{5}\cdot(-2)\)
Negatives \(k\) spiegelt am Nullpunkt: Die Plätze tauschen.
Das Zeichen kippt zu \(\gt\).
Mal negativ spiegelt: Das Zeichen kippt.
\(\fa{a} \lt \fb{b},\ k \lt 0 \;\Longrightarrow\; \fa{a}\cdot k \gt \fb{b}\cdot k\)
Multiplikation mit \(0\) zerstört die Information.
