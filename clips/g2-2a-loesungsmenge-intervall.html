Wie schreibt man
die Lösung auf?
x ≤ 1
Das ist noch keine Lösungsmenge.
L = { x ∈ ℝ | x ≤ 1 }
«alle x aus ℝ, für die gilt: x ≤ 1»
L = ] −∞ ; 1 ]
Beides ist richtig. Beides gibt volle Punkte.
x ≤ 1     ⟶     L = ] −∞ ; 1 ]
Die 1 gehört dazu. Klammer zeigt nach innen.
x < 1       ⟶     L = ] −∞ ; 1 [
Die 1 gehört nicht dazu. Klammer zeigt nach aussen.
Ein Zeichen Unterschied — ein Punkt in der Prüfung.
Auch hier gibt es die drei Ausgänge.
2x + 1 > 2x + 5      | −2x
1 > 5   falsch    ⟶   L = { }
2x + 1 > 2x − 5      | −2x
1 > −5   wahr    ⟶   L = ℝ
Wie bei Gleichungen: x weg, Aussage lesen.
1−x2 ≥ x−13      ⟶      x ≤ 1
L = { x ∈ ℝ | x ≤ 1 }
L = ] −∞ ; 1 ]
Erst jetzt ist die Aufgabe fertig.
Nie nur x ≤ 1 hinschreiben.
L = { x ∈ ℝ | x ≤ 1 }  =  ] −∞ ; 1 ]
Gefragt ist die Lösungsmenge — nicht nur die Zahl.
