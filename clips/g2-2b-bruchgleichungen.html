die Lösungsstrategie in vier Schritten
xx−2 − 4x+2 = 16x2−4
Das x steht im Nenner — Vorsicht!
Nenner ≠ 0
Durch null teilen ist verboten.
x = 2  ⟹  x−2 = 0  ⟹  nicht definiert
Also zuerst klären: Was ist überhaupt erlaubt?
xx−2 − 4x+2 = 16x2−4
x2−4 = (x−2)(x+2)
Nenner = 0  ⟹  x = 2  oder  x = −2
D = ℝ \ { −2; 2 }
Gleiche Farbe heisst: derselbe Term.
Hauptnenner: (x−2)(x+2)
xx−2 · (x−2)(x+2)  ⟶  x(x+2)
4x+2 · (x−2)(x+2)  ⟶  4(x−2)
16(x−2)(x+2) · (x−2)(x+2)  ⟶  16
x(x+2) − 4(x−2) = 16
x(x+2) − 4(x−2) = 16
x2 + 2x − 4x + 8 = 16
x2 − 2x − 8 = 0
x1,2 = 1 ± √(1+8) = 1 ± 3
x1 = 4    x2 = −2
Der zweite Kandidat hat die Farbe eines Nenners. Verdächtig.
x1 = 4     x2 = −2       D = ℝ \ { −2; 2 }
x1 = 4  ∈  D    ✓ gültig
x2 = −2  ∉  D    ✗ Scheinlösung
L = { 4 }
Die Farbe verrät es: dieser Wert stand im Nenner
und war von Anfang an gesperrt.
