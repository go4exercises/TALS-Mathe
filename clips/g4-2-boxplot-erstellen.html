Datensatz\(2,\ 4,\ 4,\ 5,\ 6,\ 7,\ 8,\ 12\)
Von der Reihe zum Bild
\(2,\ 4,\ 4,\ 5,\ 6,\ 7,\ 8,\ 12 \qquad n = 8\)
Schon sortiert — sonst wäre das der allererste Schritt.
Zuerst sortieren
\(2 \leq 4 \leq 4 \leq 5 \leq 6 \leq 7 \leq 8 \leq 12\)
Minimum und Maximum stehen damit schon da: \(2\) und \(12\).
\(n = 8 \ \text{gerade} \ \longrightarrow \ \text{Mittel der beiden mittleren}\)
\(\tilde{x} = \dfrac{5 + 6}{2} = 5.5\)
Bei ungeradem \(n\) ist es der mittlere Wert selbst.
\(\text{untere Hälfte } 2,\ 4,\ 4,\ 5 \ \longrightarrow \ Q_1 = \dfrac{4+4}{2} = 4\)
\(\text{obere Hälfte } 6,\ 7,\ 8,\ 12 \ \longrightarrow \ Q_3 = \dfrac{7+8}{2} = 7.5\)
Median der Hälften — bei ungeradem \(n\) bleibt der Median selbst aussen vor.
\(2 \ \mid \ 4 \ \mid \ 5.5 \ \mid \ 7.5 \ \mid \ 12\)
Die Achse braucht eine Teilung — sonst ist das Bild nicht ablesbar.
Sortieren, Median, Quartile.
\(\text{min},\ Q_1,\ \tilde{x},\ Q_3,\ \text{max}\)
