Datensatz\(2,\ 4,\ 4,\ 5,\ 6,\ 7,\ 8,\ 12\)
Fünf Zahlen, ein Bild
Minimum, \(Q_1\), Median, \(Q_3\), Maximum.
\(\text{Box} = Q_1 \ \text{bis} \ Q_3 = 4 \ \text{bis} \ 7.5\)
\(\text{Boxbreite} = \text{Quartilsdifferenz} = 3.5\)
Die mittleren \(50\,\%\) — nicht der Mittelwert, nicht die Hälfte der Strecke.
\(\text{Strich} = \text{Median} = 5.5\)
Der Mittelwert steht nicht im Boxplot.
Hier wäre er \(6\) — sichtbar ist er nirgends.
Liegt der Strich nicht in der Mitte der Box, sind die Daten schief.
\(\text{Antennen} \ \longrightarrow \ \text{Minimum } 2 \ \text{und Maximum } 12\)
\(\text{Spannweite} = 12 - 2 = 10\)
Jedes der vier Teilstücke enthält \(25\,\%\) der Daten —
auch wenn sie verschieden lang sind.
\(\text{links: } 4-2 = 2 \qquad \text{rechts: } 12-7.5 = 4.5\)
Lange Antenne heisst: dort streuen die Daten weit.
Kurze Box heisst: die Mitte liegt eng beieinander.
Ein einzelner Extremwert zieht nur die Antenne — die Box bleibt.
Vier Stücke, je ein Viertel.
\(\text{min} \ \mid \ Q_1 \ \mid \ \text{Median} \ \mid \ Q_3 \ \mid \ \text{max}\)
Der Boxplot zeigt keine einzelnen Werte — nur ihre Ränge.
