Warum immer 180°?
Die Erkenntnisse zur Animation «Beweis Innenwinkelsumme»
\(\fa{\alpha} + \fc{\beta} + \gamma = 180^\circ\)
Wie beweist man das, ohne zu messen?
\(\text{Parallele zu } c \text{ durch } C\)
Wechselwinkel bringen \(\fa{\alpha}\) und \(\fc{\beta}\) an die Ecke \(C\).
An Parallelen sind Wechselwinkel gleich gross.
\(\fa{\alpha} + \gamma + \fc{\beta} = 180^\circ\)
Bei \(C\) liegen die drei Winkel auf einer Geraden.
Ein gestreckter Winkel misst \(180^\circ\).
\(\gamma \gt 90^\circ\text{:} \quad \fa{\alpha} + \gamma + \fc{\beta} = 180^\circ\)
Auch stumpf bei \(C\) bleibt jeder Schritt gültig.
Nirgends wurde gemessen.
Die Wechselwinkel legen \(\fa{\alpha}\) und \(\fc{\beta}\) neben \(\gamma\) auf eine Gerade.
\(\fa{\alpha} + \fc{\beta} + \gamma = 180^\circ\)
Keine Messwerte, nur Parallelen: Das gilt für jedes Dreieck.
