Quadratische Gleichung
\(a x^2 + b x + c = 0 \quad (a \neq 0)\)
\(a x^2\): quadratisches Glied
\(b x\): lineares Glied
\(c\): konstantes Glied
\(x^2 + p x + q = 0\)
\(2x^2 + 8x - 10 = 0\)
\(\fb{\mid :2}\)
\(x^2 + 4x - 5 = 0\)
Die Lösungen bleiben dieselben.
\(x^2 = 9\)
\(x = \pm 3\)
\(\mathbb{L} = \{\fc{-3};\ \fc{3}\}\)
\(x^2 = \fb{r}\)
\(r \gt 0\): zwei Lösungen, \(x = \pm\sqrt{r}\)
\(r = 0\): eine Lösung, \(x = 0\)
\(r \lt 0\): keine Lösung, \(\mathbb{L} = \{\,\}\)
\((x - 2)^2 = 9\)
\(x - 2 = \pm 3\)
\(x = \fc{5}\;\;\text{oder}\;\;x = \fc{-1}\)
\(x^2 = 9 \;\Rightarrow\; x = 3 \quad \fd{\text{unvollständig}}\)
Auch \((-3)^2 = 9\).
Erst \(x^2\) allein auf eine Seite,
dann die Wurzel ziehen.
Zum Mitnehmen
\(x^2 = r \;\Rightarrow\; x = \pm\sqrt{r} \quad (r \ge 0)\)
\(r \lt 0: \;\; \mathbb{L} = \{\,\}\)
