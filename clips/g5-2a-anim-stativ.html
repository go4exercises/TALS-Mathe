Warum stehen drei Beine immer?
Die Erkenntnisse zur Animation «Stabil oder wackelig? — Anzahl Beine und Bodenkontakt»
\(3 \text{ Beine} \quad \text{oder} \quad 4 \text{ Beine}\)
Was ändert ein Buckel unter einem Fuss?
\(3 \text{ Beine, Buckel } 10\,\mathrm{cm}\text{:} \quad \fc{3 \text{ von } 3} \text{ am Boden}\)
Auch auf dem Buckel liegen alle drei Füsse auf.
Es steht etwas schräg, aber stabil.
\(\text{liegt auf } \fc{A\text{-}B\text{-}C}, \quad \fb{D} \text{ hängt } 10\,\mathrm{cm} \text{ hoch}\)
Mit vier Beinen tragen nur drei Füsse.
Die drei tragenden Füsse bilden ein Dreieck.
\(\text{liegt auf } \fc{A\text{-}C\text{-}D}, \quad \fb{B} \text{ hängt } 10\,\mathrm{cm} \text{ hoch}\)
Einen Moment später liegt es auf A, C und D.
Es wackelt zwischen zwei Dreiecken.
Drei Punkte legen genau eine Ebene fest, vier im Allgemeinen nicht.
\(3 \text{ Punkte, nicht auf einer Geraden} \;\Longrightarrow\; \text{genau eine Ebene}\)
Darum ist das Dreieck der Baustein jedes Vielecks.
