Wie viel zählt eine Antwort?
Die Erkenntnisse zur Animation «Einstieg · Klassenumfrage — von Rohdaten zur Verteilung»
\(\text{Anteil einer Antwort} = \dfrac{1}{n}\)
Wann ändert eine Antwort das Bild?
\(\text{Urliste: } 3,\ 5,\ 2,\ 4,\ 6 \qquad n = 5\)
Ausgezählt: fünf Säulen, jede der Höhe \(\fa{1}\).
Noch ist keine Form zu sehen.
\(\text{6. Antwort: } 3 \qquad \dfrac{1}{6} \approx 17\,\%\)
Die Säule bei 3 h wächst von \(\fa{1}\) auf \(\fa{2}\).
Eine einzige Antwort macht den Gipfel.
\(\text{22. Antwort: } 4 \qquad \dfrac{1}{22} \approx 4.5\,\%\)
Die Säule bei 4 h wächst nur von \(\fa{5}\) auf \(\fa{6}\).
Die Form bleibt: Gipfel bei 4 h.
Auszählen macht aus der Urliste eine Verteilung.
\(\text{Anteil einer Antwort} = \dfrac{1}{n}\)
Kleines \(n\): Eine Antwort kippt das Bild.
