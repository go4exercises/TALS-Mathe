Zweimal dieselbe Welle
\(\fa{\sin x} \qquad \text{und} \qquad \fb{\cos x}\)
Wie weit muss man die eine schieben, damit sie die andere ist?
Abstand der beiden Hochpunkte: genau \(\tfrac{\pi}{2}\).
\(\cos x = \sin\!\left(x + \tfrac{\pi}{2}\right)\)
Plus im Argument schiebt nach \(\textbf{links}\) — nicht nach rechts.
Umgekehrt gilt genauso: \(\sin x = \cos\!\left(x - \tfrac{\pi}{2}\right)\).
Nicht glauben — einsetzen.
\(x = 0: \quad \sin\tfrac{\pi}{2} = \fc{1} \qquad \cos 0 = \fc{1}\)
\(x = \tfrac{\pi}{2}: \quad \sin \pi = \fc{0} \qquad \cos\tfrac{\pi}{2} = \fc{0}\)
Zwei Stellen widerlegen nichts — aber sie hätten es gekonnt.
Eine Welle,
zwei Namen.
\(\cos x = \sin\!\left(x + \tfrac{\pi}{2}\right)\)
Darum genügt es, eine der beiden Kurven im Kopf zu haben.
