\(3(ax+2) \ = \ a(x+4) + 2x\)
\(a\) ist eine feste, aber unbekannte Zahl.
\(x\) ist die Unbekannte, nach der wir auflösen.
\(3ax + 6 \ = \ ax + 4a + 2x\)
Der Parameter wird mitmultipliziert wie jede Zahl.
\(a(x+4) = ax + 4a\) — beide Glieder, nicht nur das erste.
\(3ax - ax - 2x \ = \ 4a - 6\)
Ein Glied ist «mit \(x\)», wenn ein \(x\) darin steht —
\(4a\) gehört nach rechts, \(ax\) nach links.
\(3ax - ax = 2ax\), denn beide haben den Faktor \(ax\).
\(2ax - 2x \ = \ 4a - 6\)
\(\fa{(2a-2)} \cdot x \ = \ 4a - 6\)
Jetzt möchte man durch \(2a-2\) teilen.
Erlaubt ist das nur, wenn der Faktor nicht null ist.
\(a \neq 1 \quad \Longrightarrow \quad x = \dfrac{4a-6}{2a-2} = \dfrac{2(2a-3)}{2(a-1)}\)
\(L = \left\{\dfrac{2a-3}{a-1}\right\} \qquad (a \neq 1)\)
Die Bedingung \(a \neq 1\) gehört zur Antwort dazu.
\(a = 1: \quad (2\cdot 1 - 2)\,x = 4\cdot 1 - 6\)
\(\fd{0} \cdot x \ = \ \fd{-2} \quad \text{— falsch für jedes} \ x\)
\(L = \{\ \}\)
Nicht durch null teilen — den Fall gesondert einsetzen.
\(\fa{k} \cdot x = m \quad \longrightarrow \quad \fa{k} \neq 0: \ x = \tfrac{m}{\fa{k}}\)
\(\fa{k} = 0: \quad m \neq 0 \Rightarrow L = \{\ \} \qquad m = 0 \Rightarrow L = \mathbb{R}\)
Der Faktor vor x
entscheidet.
Hier wurde \(m = -2 \neq 0\), darum die leere Menge.
