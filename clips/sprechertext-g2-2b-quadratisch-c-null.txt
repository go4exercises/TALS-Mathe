0.40	Zweiter Spezialfall: Es fehlt das konstante Glied. Auch hier braucht es keine Formel — es braucht das Ausklammern.
9.90	Beide Glieder enthalten drei x. Ausgeklammert steht da: drei x mal Klammer x minus vier gleich null.
17.70	Der Nullproduktsatz: Ein Produkt ist genau dann null, wenn einer der Faktoren null ist. Also drei x gleich null oder x minus vier gleich null.
26.95	Und hier der teure Fehler: Wer die Gleichung durch x teilt, bekommt drei x minus zwölf gleich null und nur die Lösung vier. Die Null ist verschwunden — denn durch null darf man nicht teilen, und genau diesen Fall hat man weggeworfen.
39.97	Zum Mitnehmen: Fehlt das konstante Glied, ist null immer eine Lösung. Man sieht es der Gleichung sofort an — setzt man null ein, wird jedes Glied null.
