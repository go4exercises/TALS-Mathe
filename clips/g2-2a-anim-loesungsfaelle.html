Was bleibt von x übrig?
Die Erkenntnisse zur Animation «Drei Lösungsfälle · was beim Umformen mit \(x\) passiert»
\(\fa{3x+2} = \fc{11} \qquad \fa{2x+5} = \fc{2x+1} \qquad \fa{4x+8} = \fc{4(x+2)}\)
Verschwindet \(x\) beim Umformen — und was bleibt dann?
\(\fa{3x + 2} = \fc{11} \;\mid -2 \;\Longrightarrow\; 3x = 9 \;\Longrightarrow\; x = 3\)
\(x\) bleibt stehen: genau eine Lösung, \(\mathbb{L} = \{3\}\).
Die Geraden schneiden sich in \(\fb{S(3 \mid 11)}\).
\(\fa{2x + 5} = \fc{2x + 1} \;\mid -2x \;\Longrightarrow\; \fd{5 = 1}\)
\(x\) verschwindet, eine falsche Aussage bleibt: \(\mathbb{L} = \{\,\}\).
Parallele Geraden schneiden sich nie.
\(\fa{4x + 8} = \fc{4x + 8} \;\mid -4x \;\Longrightarrow\; 8 = 8\)
\(\fc{4(x+2)} = \fc{4x+8}\): \(x\) verschwindet, eine wahre Aussage bleibt.
\(\mathbb{L} = \mathbb{R}\): beide Seiten sind dieselbe Gerade.
Bleibt \(x\) stehen, gibt es genau eine Lösung.
\(\fd{5 = 1}\ \Longrightarrow\ \mathbb{L} = \{\,\} \qquad 8 = 8\ \Longrightarrow\ \mathbb{L} = \mathbb{R}\)
Verschwindet \(x\), entscheidet die Aussage, die übrig bleibt.
