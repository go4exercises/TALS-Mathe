0.40	Hast du alle x-Glieder links und alle Zahlen rechts gesammelt, steht a mal x gleich c da. Bei drei x plus zwei gleich elf ist das drei x gleich neun. a ist drei, nicht null: Du darfst durch drei teilen, x gleich drei. Genau eine Lösung, und im Bild genau ein Schnittpunkt.
16.57	Anders bei zwei mal Klammer x plus drei gleich zwei x plus neun. Ausmultipliziert: zwei x plus sechs gleich zwei x plus neun. Minus zwei x, und x ist weg. Es bleibt sechs gleich neun. Das ist falsch, egal welches x du einsetzt: Die Lösungsmenge ist leer. Im Bild sind die beiden Seiten parallele Geraden, sie schneiden sich nie.
37.41	Und bei vier x plus acht gleich vier mal Klammer x plus zwei? Ausmultipliziert steht links und rechts dasselbe. Minus vier x: acht gleich acht. Das ist immer wahr. Jede Zahl ist Lösung, die Lösungsmenge sind alle reellen Zahlen. Die beiden Geraden liegen aufeinander.
53.98	Warum ist das so? Ist a null, steht null mal x gleich c da. Null mal x ist immer null. Ist c nicht null, passt kein x. Ist c null, passt jedes.

79.47	Zum Mitnehmen: Sortiere, bis a mal x gleich c dasteht. Ist a nicht null, gibt es genau eine Lösung. Ist a null, entscheidet c: Eine falsche Aussage heisst keine Lösung, eine wahre heisst: jede Zahl ist Lösung.
