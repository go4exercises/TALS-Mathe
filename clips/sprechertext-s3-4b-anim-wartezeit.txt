0.40	Eine Bakterienkultur wächst nach zwei hoch t. Wie lange dauert es, bis eine Zielmenge y erreicht ist? Die Antwort ist der Logarithmus zur Basis zwei von y.
11.43	Von sechzehn auf zweiunddreissig Tausend steigt die Wartezeit von vier auf fünf Stunden. Denn zwei hoch fünf ist zweiunddreissig.
20.93	Von zweiunddreissig auf vierundsechzig: wieder genau eine Stunde mehr, jetzt sechs. Der Logarithmus macht aus dem Faktor zwei den Summanden eins.
30.43	Von fünfhundertzwölf auf tausend Tausend ist knapp eine Verdopplung, und die Wartezeit wächst um knapp eine Stunde, auf neun Komma neun sieben. Die Kurve wird flacher, doch jede weitere Verdopplung bringt wieder eine Stunde.
43.18	Merke: Der Logarithmus macht aus Faktoren Summanden. Jede Verdopplung kostet eine Stunde. Die Kurve wird flacher, wächst aber über alle Grenzen.
