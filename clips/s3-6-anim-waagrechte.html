Die Erkenntnisse zur Animation «Die Waagrechte am W — wie viele Lösungen hat \(|x^2-4| = c\)?»
\(|x^2 - 4| = \fb{c}\)
Bei welchen Höhen springt die Anzahl?
\(\fb{c} = 0: \quad x = \pm 2\)
Die Waagrechte trifft nur die Knicke: zwei Lösungen.
Für \(\fb{c} \lt 0\): keine Lösung.
\(\fb{c} = 3: \quad x = \pm 1, \;\; x = \pm\sqrt{7} \approx \pm 2.65\)
Für \(0 \lt \fb{c} \lt 4\): vier Lösungen.
Zwei am Buckel, zwei an den Aussenästen
\(\fb{c} = 4: \quad x = 0, \;\; x = \pm\sqrt{8} \approx \pm 2.83\)
Auf der Buckelhöhe: drei Lösungen.
Darüber, etwa bei \(\fb{c} = 6\): nur \(x = \pm\sqrt{10}\)
Anzahl Lösungen: Die Buckelhöhe \(4\) teilt die Fälle.
\(\fb{c} \lt 0\!: \ 0 \qquad \fb{c} = 0\!: \ 2 \qquad 0 \lt \fb{c} \lt 4\!: \ 4\)
\(\fb{c} = 4\!: \ 3 \qquad \fb{c} \gt 4\!: \ 2\)
Die Skizze zählt schneller als jede Fallunterscheidung.
