\(y = \log_a(x - \fa{u}) + \fb{v}\)
Was bewirkt \(\fa{u}\), was bewirkt \(\fb{v}\)?
\(y = \log_2(x - \fa{2}) \quad\Rightarrow\quad x = \fa{2}, \quad \fc{x_0} = 3\)
\(\fa{u}\) schiebt die Kurve samt Asymptote nach rechts.
Die Kurve existiert nur rechts der Asymptote.
\(\fc{x_0} = \fa{u} + a^{-\fb{v}} = \fa{2} + 2^{-\fb{1}} = 2.5\)
\(\fb{v} = 1\) hebt die Kurve, die Nullstelle rückt zur Asymptote.
Abstand zur Asymptote: \(2^{-1} = 0.5\) statt \(1\).
\(\fc{x_0} = \fa{2} + 10^{-\fb{1}} = 2.1\)
