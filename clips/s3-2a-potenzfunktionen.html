x in der Basis
\(f(x) = x^n \qquad n \in \mathbb{Z}\)
Nicht zu verwechseln mit \(a^x\) — dort steht \(x\) oben.
\(n \ \text{gerade:} \quad f(-x) = f(x) \quad \longrightarrow \quad \text{achsensymmetrisch}\)
\(W = \left[0;\infty\right[\) — eine gerade Potenz wird nie negativ.
\(n \ \text{ungerade:} \quad f(-x) = -f(x) \quad \longrightarrow \quad \text{punktsymmetrisch}\)
\(x^3: \quad (-2)^3 = -8 \qquad 2^3 = 8\)
\(D = W = \mathbb{R}\) — ungerade Potenzen erreichen alles.
Darum hat \(x^3 = b\) immer genau eine Lösung.
\(x^{-1} = \dfrac{1}{x} \qquad D = \mathbb{R}\setminus\{0\}\)
\(x \to \infty \ \longrightarrow \ f(x) \to 0 \qquad x \to 0 \ \longrightarrow \ \left|f(x)\right| \to \infty\)
Beide Achsen sind Asymptoten — Linien, denen der Graph
beliebig nahe kommt, ohne sie zu berühren.
Vorzeichen: oben oder unten.
Parität: die Symmetrie.
\(n > 0 \ \text{Parabeltyp} \qquad n < 0 \ \text{Hyperbeltyp}\)
Alle gehen durch \((1 \mid 1)\) — dort ist \(1^n = 1\) für jedes \(n\).
