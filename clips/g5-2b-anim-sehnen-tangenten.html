\(\alpha + \gamma = 51.6° + 128.4° = 180°\)
\(B\) und \(D\) verschoben: \(\alpha\) und \(\gamma\) ändern sich.
Die Summe bleibt \(180°\).
\(a + c = 4.28 + 4.09 = 8.37 = 3.89 + 4.48 = b + d\)
Der Kreis berührt alle vier Seiten.
Gegenüberliegende Seiten ergeben dieselbe Summe.
Sehnenviereck: Winkel. Tangentenviereck: Seiten.
