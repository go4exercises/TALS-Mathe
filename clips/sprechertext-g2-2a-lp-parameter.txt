0.40	In einer Parametergleichung steht neben x ein zweiter Buchstabe, hier k. Gesucht ist die Lösung für jeden Wert von k. Das heisst Parameterdiskussion.
9.95	Sortiere auf die Form a von k mal x gleich c von k: die x-Glieder links, den Rest rechts. Es entsteht k x minus zwei x gleich drei k minus sechs. Links klammerst du x aus: Klammer k minus zwei, mal x. Rechts lässt sich drei ausklammern: drei mal Klammer k minus zwei.
27.51	Ist k nicht zwei, darfst du durch k minus zwei teilen: x ist drei, für jedes solche k. Bei k gleich zwei steht null mal x gleich null. Dann ist jede Zahl Lösung. Im Bild siehst du links minus rechts als Gerade, wie bei der Normalform. Für jedes k geht sie durch die Nullstelle drei, bei k gleich zwei liegt sie ganz auf der x-Achse.
47.21	Anders bei k mal x plus eins gleich zwei x plus drei. Sortiert: Klammer k minus zwei, mal x, gleich zwei. Ist k nicht zwei, ist x gleich zwei durch Klammer k minus zwei. Bei k gleich zwei steht null mal x gleich zwei: falsch, die Lösungsmenge ist leer. Im Bild wird die Gerade waagrecht und trifft die x-Achse nie.
68.50	Eine Probe zur Formel: Für k gleich vier gibt sie x gleich eins. Eingesetzt: vier mal eins plus eins ist fünf, zwei mal eins plus drei auch fünf.
77.68	Zum Mitnehmen: Sortiere auf a von k mal x gleich c von k. Suche den Wert, bei dem a von k null wird. Dort entscheidet c von k: null heisst jede Zahl, sonst keine Lösung. Für alle anderen k ist x gleich c von k durch a von k.
