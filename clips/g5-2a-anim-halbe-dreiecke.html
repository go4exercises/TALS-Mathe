Die Erkenntnisse zur Animation «Pythagoras-Anwendung»
\(30^\circ / 60^\circ / 90^\circ \qquad 45^\circ / 45^\circ / 90^\circ\)
Welche Wurzeln bleiben stehen?
\(\fc{a = 1}, \quad \fb{c = 2}, \quad \fb{b} = \sqrt{2^2 - 1^2} = \fb{\sqrt{3}}\)
Die Höhe halbiert das gleichseitige Dreieck.
\(1 : \sqrt{3} : 2\) bei \(30^\circ / 60^\circ / 90^\circ\)
\(\fc{a = 1}, \quad \fb{b = 1}, \quad \fb{c} = \sqrt{1^2 + 1^2} = \fb{\sqrt{2}}\)
Die Diagonale halbiert das Quadrat.
\(1 : 1 : \sqrt{2}\) bei \(45^\circ / 45^\circ / 90^\circ\)
\(\fc{a = g}, \quad \fb{b = g \cdot \sqrt{3}}, \quad \fb{c = 2g}\)
Jede Seite wächst mit demselben Faktor \(g\).
Das Verhältnis bleibt \(1 : \sqrt{3} : 2\).
Zwei Verhältnisse, die man auswendig kennt:
\(1 : \sqrt{3} : 2 \qquad 1 : 1 : \sqrt{2}\)
Sie liefern die exakten Werte von sin, cos und tan in 5.3.
