\(4x^2 + 3x - x^2 + 2x - 5\)
Welche Glieder gehören zusammen?
\(\fa{4x^2} + \fb{3x} - \fa{x^2} + \fb{2x} - \fc{5}\)
Gleiche Farbe heisst: gleicher Variablenteil.
\(x\) und \(x^2\) bekommen verschiedene Farben.
\(\fa{4x^2 - x^2} + \fb{3x + 2x} - \fc{5}\)
Gleichfarbige Glieder stehen nebeneinander.
Das Minus vor \(x^2\) wandert mit.
\(\fa{(4 - 1)\,x^2} + \fb{(3 + 2)\,x} - \fc{5} = \fa{3x^2} + \fb{5x} - \fc{5}\)
Nur die Koeffizienten werden verrechnet.
