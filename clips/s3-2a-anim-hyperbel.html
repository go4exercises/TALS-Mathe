Wohin wandern die Asymptoten?
Die Erkenntnisse zur Animation «Verschobene Hyperbel»
\(y = \dfrac{1}{(x-\fa{u})^p} + \fb{v}\)
Was verschiebt \(\fa{u}\), was verschiebt \(\fb{v}\)?
\(y = \dfrac{1}{x-\fa{2}}\)
Polgerade \(x = \fa{2}\): Sie folgt \(\fa{u}\).
Die Asymptote \(y = \fb{0}\) bleibt.
\(y = \dfrac{1}{x-\fa{2}} + \fb{1}\)
Asymptote \(y = \fb{1}\): Sie folgt \(\fb{v}\).
Die Äste liegen diagonal gegenüber.
\(y = \dfrac{1}{(x-\fa{2})^2} + \fb{1}\)
Gerade Ordnung: beide Äste über \(y = \fb{1}\).
Für \(x \neq \fa{2}\): \((x-\fa{2})^2 \gt 0\), also \(y \gt \fb{1}\)
Die Asymptoten wandern mit.
\(\text{Polgerade } x = \fa{u} \qquad \text{Asymptote } y = \fb{v}\)
\(p\) ungerade: Äste gegenüber · \(p\) gerade: beide oben
